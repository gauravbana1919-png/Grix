# Session 8 — Botpress setup notes

1. Sign in to Botpress and create a bot named StudyBuddy Help.
2. Add the StudyBuddy sample knowledge base from `studybuddy_knowledge_base.md` (or upload the prepared PDF from the assignment pack).
3. Use these bot instructions:
   - Answer from the connected knowledge base.
   - If the answer is missing, say the source does not provide enough information.
   - Never invent college policies, exam dates, marks, or deadlines.
   - Use clear, student-friendly language.
4. Test at least five prompts: direct fact, summary, two-part question, unrelated question, and a question not answered by the source.
5. Open Webchat/Share/Deploy settings and copy the embed code shown by Botpress.
6. Add the exact snippet to the website and publish again. Do not paste secrets or private tokens into public files.
7. Capture screenshots of the knowledge base, test conversations, embed settings, and the live website widget.
